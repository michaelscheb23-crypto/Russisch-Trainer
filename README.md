# Russisch-Trainer – erste Testversion
Android-Kotlin-Projekt mit vier **Demo-Vokabeln**, deutscher/russischer Text-to-Speech-Ausgabe, Android-Spracherkennung, zwei Versuchen, zufälliger Auswahl und lokaler Speicherung der Position.
**Noch nicht enthalten:** direkter AnkiDroid-Zugriff, freie Auswahl der Stapel, zuverlässige Aussprachebewertung, vollständige Freihandsteuerung und ausgereifte Fehler-Wiederholung. Die Spracherkennung prüft aktuell nur eine einfache Textübereinstimmung. Dies ist ungetesteter Quellcode, keine fertige APK.

GitHub: Projektdateien und Ordnerstruktur ins Repository hochladen (nicht nur ZIP als eine Datei). GitHub Actions > Android APK > Run workflow; nach erfolgreichem Build APK im Artifact herunterladen.
